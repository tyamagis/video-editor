# VideoEditor — 自作 Windows 動画編集ソフト（フェーズ1の土台）

Adobe After Effects の代替として、自分が使う機能だけに絞って作る Windows 向け動画編集ソフト。
設計プラン（`../your_files/video-editor-design-plan/video-editor-design-plan.pdf`、v0.2）に沿って作る。
中心は「音に反応する MV エディタ」。フェーズ1ではタイムライン編集の土台を作る。

## 構成

```
VideoEditor.sln
src/
  Editor.Core/    編集ドメインモデル（プロジェクト、トラック、クリップ、キーフレーム、BPM・拍グリッド、評価エンジン、JSON保存）
  Editor.Media/   FFmpeg 連携（プローブ、サムネイル／フレーム取得、MP4書き出し）
  Editor.Audio/   NAudio 波形読み取り、MathNet.Numerics による FFT・周波数帯エネルギー（フェーズ2への拡張口）
  Editor.Render/  SkiaSharp 描画（フレーム描画、プレビュー解像度切替、タイムライン書き出し）
  Editor.App/     WPF アプリ（素材プール／プレビュー／インスペクタ／タイムラインの4ペイン）
```

依存関係：App → Core / Media / Audio / Render。Render → Core / Media / Audio。Media・Audio → Core。
Core は UI・FFmpeg・NAudio・SkiaSharp に依存しない。プレビューと書き出しは同じ `TimelineFrameRenderer` を使うため、表示と書き出し結果が一致する設計。

## 必要なもの（Windows側）

- Visual Studio 2022（「.NET デスクトップ開発」ワークロード）
- .NET 8 SDK
- ffmpeg / ffprobe（OS インストール済みのものを使う。同梱しない）

ffmpeg の確認（PowerShell またはコマンドプロンプト）：

```powershell
ffmpeg -version
ffprobe -version
```

`'ffmpeg' は、内部コマンドまたは外部コマンドとして認識されていません` と出る場合は、ffmpeg をインストールして PATH を通すこと。
実行ファイルの場所を変えたい場合は `Editor.Media/FfmpegSettings.cs` の `FfmpegExePath` / `FfprobeExePath` を変える（将来、設定画面から変えられるようにする予定）。

## 開き方・ビルド手順（Windows）

1. このフォルダを Windows 側にコピーする（例：`C:\Dev\VideoEditor`）。
2. `VideoEditor.sln` を Visual Studio 2022 で開く。
3. ソリューションを右クリック → 「NuGet パッケージの復元」（初回のみ）。
   使うパッケージ：SkiaSharp 2.88.9、SkiaSharp.Views.WPF 2.88.9、NAudio 2.2.1、
   FFMpegCore 5.1.0、MathNet.Numerics 5.0.0。
4. 構成を `Debug` / `Any CPU` にしてビルド（Ctrl+Shift+B）。
5. `Editor.App` をスタートアップ プロジェクトにして実行（F5）。

> 注意：このコードは Linux 環境で作成しており、WPF は Windows 専用のため
> 作成環境ではビルド・実行の確認ができていない。Windows での初回ビルド結果を
> 必ず確認すること。ビルドエラーが出た場合はエラーメッセージをそのまま共有してほしい。

## 最初の動作確認（スモークテスト）

1. 起動時に ffmpeg が見つからない警告が出ないこと。
2. 「ファイル → 素材を読み込む」で短い MP4（数十秒）を読み込む。素材プールに長さ・解像度が出る。
3. 素材をダブルクリックしてタイムラインに配置する。
4. プレビューに映像が出て、再生ボタンで再生ヘッドが進む。
5. タイムラインでクリップをドラッグして移動、右端をドラッグしてトリミング、再生ヘッド位置で「分割」する。
6. BPM を 120 から変えると、グリッドを「拍」にしたときに拍線の間隔が変わる。
7. 波形表示のチェックを外すと波形が消え、付けると戻る（解析データは保持される）。
8. プレビュー解像度を「1/2」「1/4」にするとプレビューが軽くなる（書き出し品質には影響しない）。
9. 「ファイル → MP4で書き出す」で 1080p/30fps の MP4 が出る。書き出した MP4 を再生して、プレビューと同じ内容か目視で確認する。
10. 「ファイル → プロジェクトを保存」で `.veproj` を保存し、開き直せる。

## フェーズ1で入っているもの

- プロジェクトモデル（JSON保存・読込、バージョン番号付き、旧版の移行の土台）
- 複数トラック（ビデオ／オーディオ／テキスト）、クリップのカット・トリミング・分割・移動・リップル削除
- キーフレーム（位置・スケール・回転・不透明度、線形／イージング／ホールド補間）
- BPM 手動設定（既定120、拍オフセット）と拍グリッド表示（フレーム／秒／拍の切替、拍へのスナップ）
- 波形表示（表示・非表示の切替付き）
- テキスト・歌詞テロップ（フォント・サイズ・色）
- 色調補正の土台（明るさ・コントラストを描画時に適用）
- プレビュー解像度切替（フル／1/2／1/4）
- MP4 / H.264 書き出し（1080p・4K、30fps・60fps、CRF・プリセット指定可）
- 周波数帯エネルギー計算の口（`IAudioBandEnergyProvider`）。フェーズ2のバインドがここから値を読む

## 未実装・未検証のもの（フェーズ1の残り／次フェーズ）

- **音声の書き出し**：タイムライン書き出し（`FrameSequenceExporter`）は現時点で映像のみ。音声トラックのミックス・AAC 合成は次のステップ。
- **Undo / Redo**：編集操作は `TimelineEditor` に集約済みだが、コマンド化と履歴は未実装。
- **キーフレーム編集 UI**：モデルと補間はあるが、インスペクタからのキーフレーム追加・編集 UI はまだない。
- **トランジション、グロー／ブラー／グリッチ／ワープ、ブレンドモード、クロマキー**：描画の差し込み口（`TimelineFrameRenderer`）はあるが、フェーズ2で1つずつ追加する。
- **BPM 自動検出と波形からのビート検出**：フェーズ2。インターフェースと未実装スタブ（`AutoBpmDetector` / `WaveformBeatDetector`）だけある。
- **無音カット、ノイズ除去**：フェーズ3。
- **プレビュー性能**：映像フレームは ffmpeg の単フレーム切り出しで取得しており、連続再生では重い。次のステップでフレームキャッシュ／デコード方式を見直す。
- **シャープ、マスク・切り抜き、PiP は作らない**（設計プラン 1章の決定通り）。
